# AleemFin v61 — Dark Mode & Home Recent Activity Refinement

Base: AleemFin v60

## Changes
- Home sub-tabs renamed from `Home / Insights` to `Recent Activity / Insights`.
- Home sub-tabs moved below Quick Entry and the dashboard-card grid, directly above the Recent Activity content.
- Recent Activity view contains the latest transactions and the accounts summary card.
- Insights view remains the dedicated Insights surface.
- Home swipe navigation now switches between `Recent Activity` and `Insights`.
- Ledger transaction cards retain the app-wide 26px card radius.
- Loan rear/history cards use a softer 18px radius and approximately 50% lower rear/front elevation shadow.
- Settings → Home Screen dashboard-card chooser has explicit 12px grid spacing.
- Added dark-mode visibility safeguards for major cards and fixed dark-text selectors that could disappear against dark surfaces.
- Version updated to 1.0.61.

## Preserved
- Existing type scale and font sizes.
- Existing color system and semantic positive/negative colors.
- Existing data calculations and storage model.
- Existing bottom-sheet behavior and navigation architecture.
