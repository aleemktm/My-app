# v59 Refinement

This release returns to the v57 Apple-native refinement as the base. The v58 visual treatment is not used as the design base.

Only the requested refinements were applied: Home Quick Entry placement, 60% hero shadow reduction, 2-or-4 dashboard card selection, consistent card/sub-tab spacing and rounded-corner treatment, Settings horizontal scroll lock, and preservation of the existing font sizes and color palette.
